## Verified

- macOS 15 arm64 and Ubuntu 24.04 x86-64 builds: eight offline tests each; Mac executable retested on macOS 27.2.
- One independent compiler comparison: identical 2,954-byte BLOCKS Code payload with matching heap directive.
- One Lightpad, firmware 1.1.0, macOS 27.2: USB/Bluetooth discovery, temporary upload, physical light/touch/MIDI, Ctrl-C restoration.
- Loss after completed transfer: old process exits; explicit discovery/upload recovers on USB/Bluetooth.
- USB `save-default` and baseline restoration: full power cycles plus physical/MIDI checks.
